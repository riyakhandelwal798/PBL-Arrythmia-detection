Arrhythmia Detection from ECG Signals using ML and DL models

Early detection of cardiac arrhythmia using automated ECG signal analysis can improve diagnostic accuracy and reduce manual interpretation time. This project aims to develop a reliable data-driven model capable of identifying arrhythmia patterns from ECG signals with high classification performance.

Problem Statement

Cardiac arrhythmias are irregular heart rhythms that can lead to severe health complications if not detected early. Traditional ECG analysis requires expert interpretation and is time-consuming. There is a need for automated systems that can analyze ECG signals efficiently and detect abnormal heartbeats accurately. This project addresses this challenge by developing an AI-based arrhythmia detection system using ECG signal data.

Literature Review / Market Research

Traditional Methods

Required manual feature extraction, limiting scalability and missing complex, non-linear heart patterns.

Deep Learning

Models like CNNs map ECG morphology while LSTMs capture temporal dependencies, automatically learning directly from raw signals.

Hybrid Architecture

Combining spatial and temporal networks shows vastly improved performance in automated classification systems.

Research Gap / Innovation

Despite the strong performance of deep learning models in ECG arrhythmia detection, several technical challenges still exist. One major issue is dataset imbalance, where normal heartbeats significantly outnumber abnormal beats, which can bias model predictions. Another challenge is model generalization across different patients, since ECG signals vary significantly between individuals. Deep learning models also require high computational resources and large annotated datasets for training. Additionally, most deep learning models behave as black-box systems, where the decision-making process is not easily interpretable for clinicians

Proposed Improvement
This project aims to address these limitations by integrating Explainable AI (XAI) techniques. Explainable AI will help interpret model predictions by highlighting important ECG signal regions responsible for classification decisions. This will improve model transparency, increase clinical trust, and support better medical decision-making. Future work will include applying explainability methods such as feature importance analysis and visualization-based interpretation techniques.

System Methodology

Dataset & Preprocessing

Dataset: MIT-BIH Arrhythmia Database (360 Hz sampling, ~110k beats, 2-channel ECG).

R-peak segmentation: 100 samples extracted before and after the peak.
Raw ECG used: Directly used instead of handcrafted features.
Normalization: Amplitudes scaled systematically.
Training limit: Number of epochs used - 10.

Signal Explanation

A standard heartbeat waveform is categorized as:

  • P wave: Atrial depolarization
  • QRS complex: Ventricular depolarization
  • T wave: Ventricular repolarization

Why R-Peak? It's the highest magnitude point in the signal, serving as the essential anchor for precise waveform alignment.

Class Imbalance Handling

Imbalance causes major statistical bias since normal beats far outnumber faults. SMOTE was avoided as it causes signal distortion in sequential data.

1. Data Augmentation: Noise injection, scaling, shifting.
2. Threshold Tuning: Range (0.3–0.5) tuned to balance Precision vs Recall.
3. Class Weights (optional): Added to firmly penalize rare-class failures.

Model Architecture

Trained heavily on sequential properties. Incorporates logic from Convolutional variants to capture temporal dependencies accurately throughout continuous tests.

Limitations

  • Dataset Imbalance Regular ECG datasets naturally contain massive amounts of normal beats and sparse abnormal beats, complicating the achievement of perfect minority classification.
  • Lack of Multi-Class Detection Currently, the model is built for binary classification (Normal vs Arrhythmia) and cannot individually identify distinct forms of heart arrhythmias.

Future Work

  • Multi-Class Classification Expanding the model layers to categorize specific distinct conditions simultaneously.
  • Real-Time Monitoring Seamless deployment into edge devices and wearables for rapid continuous rhythm reading.
  • Explainable AI (XAI) Integrating advanced XAI visualizers into clinical dashboards to provide healthcare professionals with deeper model interpretability.
